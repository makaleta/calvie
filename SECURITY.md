# Security Policy

## Supported Versions

Security fixes are provided for the latest released version only. Please update
to the latest release before reporting a vulnerability.

## Reporting a Vulnerability

Report suspected vulnerabilities privately to [mk@m1k.cz](mailto:mk@m1k.cz).
Do not disclose vulnerabilities in public issues or pull requests.

Include the affected version, steps to reproduce, and the potential impact.
Remove credentials, private calendar URLs, and personal data from your report.

Please allow time to investigate and release a fix before public disclosure.
